Why this exists

Built for the moment your connection breaks.

DNS poisoning, blocked traffic, and connection resets are a daily reality on some networks. The fix is usually a hotspot — but Windows makes you click through Settings every time.

The daily annoyance
“My ISP breaks DNS, blocks traffic, or resets the connection. Switching to a hotspot should not take ten clicks.”

WinAdapterSwitcher was built from that exact workflow: keep the common network fixes one right-click away, and leave the deeper controls in a small, readable settings window.

The problem Windows buries adapter controls.

Settings → Network & Internet → Advanced network settings → More network adapter options → right-click → Disable/Enable.

The fix Two tray actions cover the common cases.

Wired only and wireless only enable one side and disable the other. Everything else is one more click away.

Features

Small tool. Complete control.

No installer, no background service, no account. Just a tray icon and the network controls you actually use.

One-click modes

Wired only, wireless only, enable all, or disable all. The destructive option asks for confirmation first.

Per-adapter control

See every adapter on the system and toggle exactly the one you need, without changing the rest.

Eight languages

简体中文, 繁體中文, English, 日本語, 한국어, Deutsch, Français, Español. Follows Windows on first run.

Auto-start that works

Uses a highest-privilege scheduled task, so Windows does not silently block the app at sign-in.

CLI and shortcuts

Use --wired, --wifi, --enable NAME, and --disable NAME from scripts, shortcuts, or scheduled tasks.

Portable and private

One exe, config next to it, no installer, no telemetry, no network calls. Delete the folder to remove it.

How it works

From download to switched network in seconds.

No setup wizard. The first run detects adapters automatically and saves them next to the exe.

01

Download and unzip

Grab the release zip and extract it anywhere. There is no installer.

02

Run the exe

Approve the UAC prompt once so Windows allows adapter changes.

03

Use the tray

Right-click the icon and pick a mode. Double-click for settings.

FAQ

Good to know.

Do I need administrator rights?

Yes. Windows requires elevation to enable or disable network adapters. The exe declares requireAdministrator, so Windows shows a UAC prompt at launch.

Does it install anything?

No. It is a single portable exe. If you enable auto-start, it creates one scheduled task for the current user. Turning auto-start off removes that task.

Does it collect data?

No. The app has no network access, telemetry, or ads. Settings are stored in config.ini next to the exe.

Why a scheduled task for auto-start?

Windows is unreliable when launching elevated apps from the Run key. A highest-privilege logon task starts reliably without an extra UAC prompt.

Can I use it from scripts?

Yes. Use the command-line flags. If the app is already running, the command is forwarded to the existing instance.
