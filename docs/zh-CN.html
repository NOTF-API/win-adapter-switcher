为什么做这个

为网络突然不可用的那一刻而做。

DNS 污染、连接拦截、直接 RESET，在一些网络里是日常。通常切到手机热点就能解决，但 Windows 每次都要重新翻设置。

日常痛点
“运营商 DNS 污染、拦流量、直接 RESET，切个热点不该点十几次。”

WinAdapterSwitcher 就是从这个工作流来的：把最常用的网络操作放在托盘右键菜单里，把更深一层的控制留在简洁的设置窗口。

问题 Windows 把网卡控制藏得太深。

设置 → 网络和 Internet → 高级网络设置 → 更多网络适配器选项 → 右键网卡 → 禁用/启用。

解决 两个托盘操作覆盖常见场景。

“仅开启有线网络”和“仅开启无线网络”会开启一侧并关闭另一侧；其他操作也只多一次点击。

功能

小工具，完整控制。

无需安装、无后台服务、无账号。只有托盘图标和你真正会用的网络控制。

一键模式

仅开启有线、仅开启无线、启用全部、禁用全部。破坏性操作会先确认。

单网卡控制

查看系统里的所有网卡，只切换你需要的那一个，不影响其他网卡。

八种语言

常见问题

你需要知道的。

需要管理员权限吗？

需要。Windows 修改网卡状态必须提权。exe 声明了 requireAdministrator，启动时会弹 UAC。

会安装东西吗？

不会。只有一个绿色 exe。开启开机自启会创建当前用户的计划任务，关闭时会删除该任务。

会收集数据吗？

不会。程序不联网、无遥测、无广告。配置保存在 exe 同目录的 config.ini。

为什么用计划任务自启？

Windows 对 Run 注册表中提权程序的登录启动不可靠；最高权限计划任务可以稳定启动，且不会额外弹 UAC。

可以在脚本里调用吗？

可以。使用命令行参数；程序已运行时，命令会转发给现有实例。
